# Chocolate-Sales
Chocolate sales refer to the buying and selling of different chocolate products across various countries and customers. This data includes details such as sales amount, product type, country, and sales person, which help track how well each chocolate product is performing.

🍫 Chocolate Sales Analysis Project

📌 Overview

The Chocolate Sales Analysis Project is a data analysis and business intelligence project focused on understanding sales performance using real-world style chocolate sales data.
The project transforms raw sales records into clear insights that help answer important business questions such as which products sell the most, which regions generate the highest revenue, and how sales change over time.

This project is ideal for demonstrating data analysis skills, Python proficiency, and business-oriented thinking.

.

🎯 Purpose of the Project

Companies often collect large amounts of sales data but struggle to convert it into useful information.
This project aims to bridge that gap by:

- Analyzing sales trends and patterns

- Identifying high-performing products and regions

- Understanding seasonal demand

- Supporting data-driven decision-making


🎯 Project Objectives

- Calculate total sales revenue and total units sold

- Identify top-selling and least-selling chocolate products

- Analyze sales performance across different regions

- Study monthly and seasonal sales trends

- Compare product categories (Milk, Dark, White, etc.)

- Evaluate salesperson performance

- Create meaningful visualizations for better understanding

📂 Dataset Description

The dataset consists of structured chocolate sales transaction data.

Common Columns Included:

Column Name	Description
Sales Person    Persons responsible for the sales
Order Date	Date of the sale
Product Name	Name of the chocolate product
Category	Chocolate type (Milk, Dark, White, etc.)
Country 	Country names who buys chocolate
Amount   	Price of chocolate 
Boxes Shipped   How many boxes are delivered

- Total revenue calculation

- Product-wise sales analysis

- Region-wise revenue comparison

- Monthly and seasonal trend analysis

- Category-wise performance evaluation
